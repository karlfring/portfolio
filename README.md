# Portfolio de Karl Akpovi, Data Analyst

Site publié sur [karlfring.github.io/portfolio](https://karlfring.github.io/portfolio/).

Chaque projet est présenté en trois temps : contexte, réalisation, résultat.

## Contenu

| Fichier | Rôle |
|---|---|
| `index.html` | page d'accueil (application React compilée) : projets, expérience, compétences, formation, contact |
| `assets/` | code compilé de la page d'accueil (JavaScript, CSS, police Geist) |
| `vgc.html` | étude de cas de [VGC Meta Overview](https://github.com/karlfring/vgc-meta-observatory) |
| `procedure-graphique-analyse.html` | procédure pour créer un graphique d'analyse |
| `kit-onboarding-powerbi.html` | kit de formation Power BI pour référents métier |
| `style.css` | feuille de style des pages secondaires |
| `img/` | captures des tableaux de bord au format WebP, avec une variante 800 px pour mobile (`-800.webp`) |

## Technique

La page d'accueil est une application React compilée (Vite, Tailwind CSS),
publiée telle quelle par GitHub Pages depuis la branche `main`. Les pages
secondaires restent en HTML et CSS statiques.

- Le fond animé de l'en-tête ne tourne que sur ordinateur (écran large et
  souris). Sur mobile, ou si l'utilisateur a demandé moins d'animations, il
  reste figé.
- Les captures sont servies en 800 px sur mobile et en pleine taille sur
  ordinateur.
- L'ancienne page d'accueil en HTML reste disponible sur la branche
  `version-html`.
